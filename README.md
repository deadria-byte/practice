# Restaurant Skill Lab — Project Home

This repository is the working home for AKR Operations' Restaurant Skill Lab (consumer brand: Back of House Blueprint) — the plan to reach $3,000+ monthly recurring revenue by December 31, 2026. It's named "practice" on GitHub for historical reasons; that name doesn't affect the product. Rename it anytime in GitHub → Settings if you want the label to match.

## What's in here, and why

- **`business-brief.md`** — the shared context (goal, pricing, audience, brand voice, non-negotiables) every agent in this repo reads before doing any work. If your strategy changes, update it here first.
- **`planning/full-plan.md`** — the complete 23-week, phase-by-phase roadmap.
- **`.claude/agents/`** — four specialist AI workers (Market Signal Researcher, Offer Architect, Content Angle Strategist, Conversion System Builder), each with exactly one job. Claude Code reads this folder automatically.
- **`runbook.md`** — the exact order to run those four agents in, and what happens to their output.
- **`outputs/`** — where finished, ready-to-review drafts land after a pipeline run. Nothing here is published automatically.

## How to use this, day to day

Tell Claude Code what you want in plain language — e.g. "run the pipeline on Food Cost and Inventory" — and it will run the four agents in order and hand you back a draft in `outputs/` to review. You approve or send it back; nothing goes live on its own.
